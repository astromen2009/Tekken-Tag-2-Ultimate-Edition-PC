## Instalador para Windows / Windows installer

**Descarga `TTT2-Setup-Windows-*.exe` y ábrelo.** El instalador:

1. Se instala en tu usuario (no necesita permisos de administrador).
2. Te pide tu copia del juego: **TEKKEN TAG TOURNAMENT 2 Wii U EDITION, versión europea (WUP-P-AKNP), con la actualización v16, como archivo `.wua`** (Cemu crea uno a partir de un juego instalado: *Herramientas → Convertir a formato comprimido .wua*).
3. Te pide la carpeta donde instalarlo (unos 17 GB).
4. Compila el programa del juego para tu PC (unos minutos; necesita ~1,5 GB libres y 4 GB de RAM o más) y copia el juego.
5. Deja **Tekken Tag Tournament 2** en el menú Inicio.

**El juego no viene incluido**: el programa se genera en tu PC a partir de tu propio `.wua`, porque contiene código del juego y no se puede distribuir.

Requisitos: Windows 10/11 de 64 bits, un procesador con AVX2 (Intel Haswell / AMD Excavator o más nuevo) y una GPU con Vulkan 1.3 (drivers actuales de AMD, NVIDIA o Intel).

Si algo falla, el mensaje de error explica qué pasó; los registros de la compilación quedan en `%LOCALAPPDATA%\ttt2\setup-work\logs`. Para volver a instalar o actualizar, abre **Instalar Tekken Tag Tournament 2** en el menú Inicio.

**Download `TTT2-Setup-Windows-*.exe` and run it.** It asks for your own copy of the game (TEKKEN TAG TOURNAMENT 2 Wii U EDITION, Europe, update v16, as a `.wua`) and a folder, builds the game program for your PC from it and installs the game with a Start menu shortcut. The game is not included.
